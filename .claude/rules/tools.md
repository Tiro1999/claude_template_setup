# Tools to use

Most likely the project you´re working on already has .vscode/tasks etc. so you can have all those as a working toolbox to test and review.

- You can ask if you dont know how to create a testbuild of the software
- You are allowed to create test build configurations beside the mainbuild
- You are allowed use project tools for build, flash, test, log
- before test flashing you should be sure what testhardware youre allowed to use
- Logging files should only be stored locally (gitignored)
- Own developer notes should only be stored locally (gitignored)
- if the project contains a Docker devcontainer setup you can always use it

- For Documentation Tools you are allowed to use markdown as far as it matches the [Projectrules](project.md).
- To visualize documentation you are allowed to use drawio.svg files while respect the [Projectrules](project.md).
- To have a perfect user friendly software documentation overview you are allowed to use an HTML format file
